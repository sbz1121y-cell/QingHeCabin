# 运行验收与录屏步骤

2026-11-17 在 Huawei_Phone API17 模拟器完成以下验证。14项自动集成断言见 device-tests.json；表中也注明仅经纯业务测试覆盖的子项。录屏和截图均由真实模拟器画面取得。

|步骤|操作|预期结果|实际结果|
|---|---|---|---|
|1|启动应用，拍摄温室页面|显示默认指标与3台设备|通过；首次启动观察到28/55/480，后续01-overview为高温场景|
|2|点击高温干燥，滚动到设备|温度36、湿度28；风扇与灌溉泵开启|通过；02-hot-scene.jpeg，实际存档记录联动|
|3|关闭风扇，查看状态|显示手动接管|通过；03-manual.jpeg；接管期间再计算不覆盖由单元测试验证|
|4|点击交还自动|高温条件下风扇重新开启|通过；日志中有交还与重新开启事件|
|5|点击风扇模拟离线|离线设备关闭且开关不可操作|通过；04-offline.jpeg；离线控制返回错误另有单元测试|
|6|恢复在线，进入规则页并新建规则|规则被保存并影响设备状态|通过；PriorityGuard已落盘且恢复后可见|
|7|输入空名称、越界阈值或优先级100|显示清晰错误且不保存规则|空名界面实测通过；06-validation.jpeg；阈值和优先级异常由单元测试验证|
|8|创建优先级99的高温关闭风扇规则|冲突时高优先级关闭规则获胜|通过；实际存档fan=false，reason=规则：PriorityGuard|
|9|查看日志并切换筛选|看到对应操作与筛选结果|通过；11-logs.jpeg、12-filtered-logs.jpeg|
|10|推进仿真3次|指标按设备状态变化，序号递增|通过；32.4°C、37%、590lx，tick=3|
|11|记录状态，等待保存|Preferences产生可读取快照|通过；preferences-before.xml|
|12|强制停止应用再启动|业务状态与停止前一致|通过；7个业务字段相等，页面值和规则可见性断言通过|
